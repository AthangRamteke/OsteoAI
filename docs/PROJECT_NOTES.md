# OsteoAI - Project Notes

## Project Overview

OsteoAI is an AI-powered osteoporosis risk assessment system designed to identify individuals who may be at risk of osteoporosis before severe symptoms appear.

The system combines a modern React frontend, Machine Learning prediction model, Explainable AI (SHAP), and an AI Health Assistant to provide personalized health insights.

# Engineering Decisions

## Decision 1

Use React with Vite.

Reason:
Fast development, excellent performance, and modern frontend architecture.

---

## Decision 2

Use Material UI.

Reason:
Provides professional healthcare-style components and responsive layouts.

---

## Decision 3

Store all form values inside a single formData object.

Reason:
Simplifies state management and future API integration.

---

## Decision 4

Use one generic handleChange() function.

Reason:
Avoids duplicate code and improves scalability.

---

## Decision 5

Calculate BMI automatically.

Reason:
BMI is a derived value and should not require manual user input.
